## How releases will work

The structured listings and generated README will come from the same verified release bundle as the website directory. Each published listing must include a source URL and verification date. Checks reject draft or empty data and a README that differs from the structured listings. A failed refresh must preserve the last successful release.

This is a selected directory, not a count of the whole UK jobs market. A job leaving the directory does not by itself mean that the employer closed it.
